# ポートフォリオ用サンプル画面・サンプル動画

実際に運用しているシステムの画面を、**架空のデータに入れ替えて**書き出したものです。
デザイン・レイアウト・配色・部品の構造は、本番とまったく同じものを使っています。

## 動画（2本）

| ファイル | 内容 | 長さ |
|---|---|---|
| `movie_01_open_spots.webm` / `.gif` | PC：物件一覧で物件名を押す → 区画一覧が開く → 表をスクロール | 約14秒 |
| `movie_02_open_spots_mobile.webm` / `.gif` | スマホ：物件をタップ → 引き出しが開く → 1区画1カードをスクロール | 約15秒 |

`.webm` が高画質（VP8）、`.gif` はそのまま貼れる形です。用途に合わせてお使いください。
画面の上に出ている丸い印は、指／マウスの位置を分かりやすくするために重ねたものです。

## 確認ずみのこと

- **実データは1件も入っていません。** 物件名・人名・住所・電話番号・金額・会社名・
  メールアドレスは、すべて架空のものです。実在の物件名30件・実在の会社名・
  実在の連絡先を、機械（文字列照合）で全ファイル検査して0件を確認しています。
- **社名・サービス名は出していません。** 画面の呼び名は
  「駐車場管理システム」「清掃勤怠システム」「入居時チェック」、
  会社名は「サンプル管理株式会社」です。
- **外部との通信はありません。** CSSは中に埋め込みずみ、外部の読み込み先
  （先読み・PWA・CDN・Firebase・Google Apps Script）はすべて外してあります。
  14枚すべてを実際にブラウザで開き、外部リクエスト0件・JSエラー0件を確認しました。
- 中に入っている `<script>` は、開いたときに表示位置をそろえるだけの数行です。通信はしません。
