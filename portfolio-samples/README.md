# ポートフォリオ用サンプル画面

実際に運用しているシステムの画面を、**架空のデータに入れ替えて**書き出したものです。
デザイン・レイアウト・配色・部品の構造は、本番とまったく同じものを使っています。

## ファイル

| ファイル | 画面 | 端末 |
|---|---|---|
| `01_parking_list.html` | 駐車場管理システム 物件一覧＋区画一覧（1件を展開） | PC 1680px |
| `02_contract_kanban.html` | 駐車場管理システム 契約カンバン | PC 1440px |
| `03_parking_list_mobile.html` | 駐車場管理システム 区画一覧（1区画＝1カード） | スマホ 375px |
| `04_cleaning_attendance.html` | 清掃勤怠システム 勤怠・出勤カレンダー | スマホ 390px |
| `05_move_in_check.html` | 入居時チェック お部屋の状態確認 | スマホ 390px |

同名の `.png` は、それぞれの画面をそのまま撮ったものです。

## 確認ずみのこと

- **実データは1件も入っていません。** 物件名・人名・住所・電話番号・金額・会社名は、すべて架空のものです。
- **社名・サービス名は出していません。** 画面の呼び名は「駐車場管理システム」「清掃勤怠システム」「入居時チェック」、会社名は「サンプル管理株式会社」です。
- **外部との通信はありません。** CSS は中に埋め込みずみ、外部の読み込み先（先読み・PWA・CDN）はすべて外してあります。ブラウザでファイルを開くだけで表示できます。
- 中に入っている `<script>` は、開いたときに表示位置をそろえるだけの数行です。通信はしません。
